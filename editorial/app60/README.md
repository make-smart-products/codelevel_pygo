# Личный Telegram-бот — результат публикации 60

Python 3.12+, SQLite, Telegram Bot API. Сторонние библиотеки не нужны.
Команды: /add, /note, /list, /notes, /done, /delete, /search, /export, /help.
Только указанный владелец в личном чате получает доступ к данным.
Задачи и заметки сохраняются между перезапусками. Поиск учитывает Unicode casefold.
Экспорт идёт отдельными JSON-записями в сообщениях; полный файл экспорта — тема продолжения.

## Запуск

1. Создайте отдельного бота в @BotFather. Токен бота-публикатора канала не используйте.
2. Скопируйте `.env.example` в `.env`. Заполните токен и свой числовой Telegram ID
   в `TELEGRAM_OWNER_ID`. Токен не отправляйте в чат и не коммитьте.
3. Выполните `python bot.py check`, затем `python bot.py run` в этой папке.
4. Откройте личный чат со своим ботом: `/start`, `/add Проверить приложение`, `/list`.
5. Остановка: Ctrl+C. Для непрерывной работы нужен постоянно включённый сервер.
   Локальные команды запуска сами по себе не создают облачный сервис.

Long polling не требует публичного домена. У этого токена не должен работать
другой получатель getUpdates или webhook. Бот не отключает webhook автоматически.
Файлы `.env`, `data` и резервные копии содержат приватные данные.

## Проверки и резервирование

```text
python -m unittest discover -s tests -v
python backup.py data/notes.db backups/notes-backup.db
```

Копирование использует SQLite backup API и integrity_check.
Для восстановления остановите бота, сохраните старый каталог данных в отдельном
месте и замените базу проверенной копией. Старая копия offset может повторно
обработать доступные Telegram-обновления — восстанавливайте с учётом этого.

## Неопределённая доставка

Команда и ответ записываются одной транзакцией, повтор update_id не повторяет действие.
Перед sendMessage ответ помечается `sending`. Если Telegram не подтвердил результат,
бот останавливает отправку: автоматически повторять ответ небезопасно.
Проверьте чат и ID доставки из ошибки. Если ответ доставлен:

`python bot.py resolve --outbox-id 12 --delivered`

Если убедились, что ответа нет, разрешите повтор явно:

`python bot.py resolve --outbox-id 12 --retry`

Затем снова запустите бота. Один токен запускается одним процессом.
Тексты записей и токен не печатаются в журнал работы.

Проверено локально на тестовых данных. Подключение реального личного бота
требует нового токена и owner ID; в рамках подготовки публикаций оно не выполнялось.
Источник: https://core.telegram.org/bots/api
