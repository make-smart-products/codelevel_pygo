# Новый формат CodeLevel

По прямой просьбе пользователя сообщения 19–33 удалены из канала.
Подтверждение: replacement.json. Старый курс остановлен маркером
course-retired.json; прежние материалы сохранены только как архив проекта.

Пять новых обзоров: Python, Go, JavaScript/TypeScript, Java/C# и Rust.
Тексты: cards.json. Картинки: images/. Все пять созданы встроенным ImageGen,
промпты сохранены в prompts.json. Это иллюстрации, не измерения производительности.
Источники указаны в каждой подписи. Отправленные сообщения: published.json.

## Автоматическое продолжение

skills_content.py создаёт последовательность модулей Python и Go.
Каждый модуль содержит 3 иллюстрированные карточки и 2 нативные викторины:
предсказание вывода и проверку понимания правила. У викторины четыре разных
варианта, один правильный и короткое объяснение.

Варианты ответов перемешиваются детерминированно. Правильный индекс
вычисляется после перемешивания. В новых циклах меняются входные данные;
это осознанное повторение 24 изучаемых тем, а не обещание бесконечного
числа новых тем или ИИ-генерации в облаке.

Изображения используются как обложки тематических серий повторно.
У quiz также запрашивается изображение в media описания — функция актуального
Telegram Bot API; старые клиенты могут показывать poll отдельно от картинки.

prepared-605.jsonl — конкретный предварительно собранный запас 605 материалов.
После него программа продолжает проверяемые вариации по тем же правилам.
Для расширения программы добавляйте новые семейства в RECIPES и проверки.

## Расписание и прогресс

skills_publish.py, по 5 материалов за запуск. Cron:
7-59/10 * * * * — минуты 07,17,27,37,47,57 каждого часа.
Курсор .skills-publication-state.json отдельно хранит следующую запись,
активную пятёрку и неподтверждённую доставку. Резервирование записывается
в git до отправки, результат — после подтверждения Telegram.

GitHub Actions может задерживать и пропускать cron:
https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule
Поэтому это настроенный десятиминутный график, а не гарантия фактической точности.
Для устойчивого интервала нужен постоянный сервер с этим публикатором.
При неизвестном результате доставки отправка останавливается до проверки канала.

Python-вывод, периодичность, защита от дублирования, payload викторины.

python editorial/language_cards/validate_skills.py — компиляция и выполнение
48 Go-примеров, сборка предварительного запаса. Для неё локально нужен Go.
Сам облачный публикатор использует только стандартную библиотеку Python.
