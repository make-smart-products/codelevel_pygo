# CodeLevel: личный Telegram-бот и развитие навыков

300 публикаций, 60 учебных модулей по 5 постов.

Посты 1–5 обновлены вводным блоком Python и Go: пять MP4-анимаций
по 24 секунды с разбором моделей выполнения, компромиссов, конкурентности,
выбора языка и перспектив. Исходники, источники и подтверждения редактирования:
[intro](intro/sources.md). Сообщения Telegram сохранены под прежними ID 19–23.

- 1–60: создаём готового личного Telegram-бота. Проверенный код: [app60](app60/README.md).
- 61–150: проектируем и реализуем развитие: редактирование, теги, напоминания,
  пользователи, импорт, PostgreSQL, очереди, контейнер и эксплуатация.
- 151–300: Python, Go, алгоритмы, типы, тесты, конкурентность, контракты,
  безопасность, производительность и самостоятельный проект.

Материалы продолжения — упражнения для реализации. Они не объявляются
заранее реализованными возможностями образца первой версии.
Примеры отмечены как самостоятельные либо как фрагменты контекста.

## Материалы

- [Просмотр и поиск по всем постам](pack/index.html).
- [Полный текст по разделам](pack/README.md).
- [Очередь JSONL для публикатора](pack/queue.jsonl).
- [Результат автоматической проверки](pack/validation.json).
- `course_topics.txt`: авторские учебные карточки с примерами, ошибками и решениями.
- `generate_course.py`: пять частей модуля и последовательность публикаций.
- `build_pack.py`: валидация и экспорт.

Сборка: `python editorial/generate_course.py`.
Проверки: `python -m unittest discover -s tests -v` и
`python -m unittest discover -s editorial/app60/tests -v`.
Код бота использует только стандартную библиотеку Python 3.12+.

Публикатор читает подготовленную конечную очередь. Отдельный курсор
`.course-publication-state.json` не смешивается с историей прежних упражнений.
После поста 300 новые сообщения автоматически не генерируются.
