## 0001. Python и Go: что происходит при запуске

Python и Go: что происходит при запуске

Python динамически типизирован: тип относится к объекту, а имя может ссылаться на разные объекты. Аннотации помогают инструментам, но сами по себе не проверяют типы при запуске. CPython обычно компилирует код в байткод, который выполняет его среда.

Go статически типизирован: многие несовпадения типов выявляет компилятор. Сборка создаёт исполняемый файл со средой Go. Часто его удобно переносить отдельно; CGO и внешние ресурсы могут добавить зависимости.

В анимации — учебная схема, без измерения скорости. Общие черты: оба языка высокоуровневые и используют автоматическое управление памятью.

## 0002. Сильные стороны и цена удобства

Python и Go: сильные стороны и ограничения

Python: выразительный код, автоматизация, анализ данных, ML и большой выбор библиотек. Подходит для быстрой проверки идеи. Цена: управление окружениями, ошибки типов без достаточных проверок, затраты на чистые Python-циклы. Нативные библиотеки могут выполнять тяжёлые вычисления вне этих циклов.

Go: статические проверки, единый стиль gofmt, goroutines, стандартные сетевые инструменты и удобная сборка сервисов. Цена: более явный код обработки ошибок и менее широкий выбор инструментов для исследовательской работы с данными.

Ни один язык не отменяет тесты, профилирование и хороший алгоритм. Потребление памяти и скорость измеряют на своей нагрузке, а не по лозунгу «X быстрее Y». #Python #Go

## 0003. Конкурентность: Python async и Go goroutines

Конкурентность: ожидание — не вычисление

Python async/await позволяет переключаться между кооперативными задачами во время ожидания сети. Блокирующий вызов может остановить event loop: async не превращает любой код в неблокирующий.

Go запускает goroutines, которые runtime распределяет по потокам ОС. Это удобно для множества независимых сетевых операций, но нужны отмена, ограничения числа работ и защита общей памяти.

В обычном CPython с GIL потоки не распараллеливают чистые Python CPU-циклы. Есть процессы, нативные расширения и отдельные free-threaded сборки начиная с 3.13; совместимость зависимостей нужно проверять.

Схема в видео не является бенчмарком. Конкурентность — организация нескольких работ; параллелизм — их одновременное выполнение. #Python #Go

## 0004. Когда выбирать Python, когда Go

Как выбрать язык под задачу

**Разбор:** Создай задачу и заметку, найди их, перезапусти, заверши задачу, экспортируй запись и проверь копию. Секреты не публикуй.

Завершение модуля: сверьте решение с результатом собственного опыта. Если оно отличается, объясните причину и поправьте проверку. В следующем модуле перейдём к «Редактирование записи».

Источники: https://core.telegram.org/bots/api, https://docs.python.org/3.12/library/sqlite3.html
