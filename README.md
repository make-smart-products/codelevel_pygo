# CodeLevel | Python & Go

Канал: https://t.me/codelevel_pygo

Текущий формат: профессиональные иллюстрированные обзоры языков, практические
карточки Python и Go и нативные Telegram-викторины с четырьмя вариантами ответа.

## Расписание

По 5 материалов за запуск; настройка каждые 10 минут на минутах 07,17,27,37,47,57.
Workflow: .github/workflows/publish.yml, команда python skills_publish.py.
GitHub может задерживать или пропускать cron; для устойчивого интервала нужен VPS.
Проверка подключения без отправки: python skills_publish.py --check.
Предпросмотр следующих пяти материалов: python skills_publish.py --preview.

В GitHub Actions Secrets хранится TELEGRAM_BOT_TOKEN. Локальный .env исключён из git.
Прогресс: .skills-publication-state.json. Перед каждой отправкой резервируется
событие, после подтверждения сохраняется ID сообщения. При неизвестном результате
доставка останавливается: проверьте канал, затем разрешите pending вручную.

## Материалы и генерация

Пять иллюстраций и обзорных постов: editorial/language_cards/.
Шаблоны, объяснения и варианты: skills_content.py — 24 семейства Python/Go.
Каждый учебный модуль: 3 карточки с картинками и 2 викторины. Новые циклы меняют
входные данные и порядок вариантов. Это авторские проверяемые шаблоны, не
ИИ-генерация в облаке; новые темы добавляются отдельной редакционной работой.
Пять обложек тематических серий используются повторно.
Запас для просмотра: editorial/language_cards/prepared-605.jsonl.

## Проверки

python -m unittest discover -s tests -q
python editorial/language_cards/validate_skills.py

Первая команда проверяет в том числе лимиты 5005 будущих материалов и Python-ответы.
Вторая компилирует и выполняет 48 Go-примеров (нужен Go локально).
Облачный публикатор использует только стандартную библиотеку Python 3.12+.

## Архив

По просьбе пользователя посты 19–33 удалены. Подтверждение: replacement.json
в editorial/language_cards. Прежняя серия из 300 уроков остаётся в editorial/pack
как архив, её автоматическая отправка остановлена course-retired.json.
Код учебного личного бота: editorial/app60; он не является публикатором канала.
